# Marquez portfolio

Astro + TypeScript + Tailwind CSS. The first version implements the hero and a compact focus section.

## Local development

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
```

Deploy the repository to Vercel using the Astro preset. Build command: `npm run build`. Output directory: `dist`. This site is static and does not need a server adapter.
